## 仓库说明

本仓库为共用电子队 CRTC2026 中期考核的文档材料仓库。按参赛手册文档规范，所有文档统一放置于根目录下的 `docs/` 文件夹中，采用 Markdown 格式，按时间顺序组织，每个功能为一个独立板块（H2 标题为功能名称，正文为该功能的描述与开发历程）。

## 目录

| 文件 | 内容 |
| --- | --- |
| `docs/01-开发日志.md` | 开发日志：各功能板块的功能描述与开发历程、队员个人贡献摘要、开源项目使用说明 |
| `docs/02-规划与采购单.md` | 核心部件选型与理由、采购清单与成本预算、实物型号差异说明 |

## 说明

本队机器人由队员自行设计、加工与编程制作：机械结构（三轴机械臂、夹爪、底盘承载结构）为自行建模并 3D 打印/外包切割加工，电控与视觉程序均为本队自行编写。所使用开源资源的说明见 `docs/01-开发日志.md` 末尾「开源项目使用说明」。中期考核演示视频以邮件附件形式提交。

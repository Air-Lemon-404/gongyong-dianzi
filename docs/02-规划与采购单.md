## 四、核心部件选型理由（💡 为什么）

- **MG310 减速电机（30~60rpm 档，带编码器）**：低转速大扭矩，满足底盘载重与全向机动需求；虽最终评估后放弃使用编码器（开环 PWM 已足够，见开发日志 10/17 记录），但带编码器版本为后续闭环升级预留了硬件可能。
- **TB6612 电机驱动模块（×4）**：双路驱动单片可带 2 轮、体积小、效率高，利于双层底盘的紧凑布局；4 片正好对应 4 轮独立通道。
- **MG996R + SG90 舵机组合**：MG996R 金属齿轮、扭矩大，用于机械臂底座等受力部位；SG90 轻量小巧，用于夹爪等末端轻载环节；均按"在用 + 备件"配置，防单点损坏卡进度。
- **5V 5A DC-DC 降压模块**：舵机独立 5V 供电（星形分电），避免舵机堵转电流拉低主控电压导致复位。
- **XH2.54 插接件 + 万用板（自行画板焊接）**：替代面包板——面包板易松动，焊接连接可靠性高，适合振动工况（9/27 会议决策）。
- **麦克纳姆轮 60mm**：实现全向移动（平移 + 原地旋转），机动性优于普通轮。
- **碳纤维/铝板激光切割底盘**：减重 + 高刚度，设计后外包切割加工，兼顾精度与强度（9/27 会议决策，10 月落地上切割）。
- **18650 动力型电池 ×8 + 双节带线电池盒**：2S 供电（7.4V 标称）匹配电机与驱动电压，双盒便于分组更换充电。
- **PS2 无线手柄（锁定款）**：手册指定的遥控方案，锁定款避免信号漂移失控。

## 五、实物型号与采购清单差异说明

装配与到货过程中，实物选用的个别型号与 9/27 初版清单存在迭代，记录如下，确保报销凭证与实物一致：

- **舵机 SG90 → SG92R（10/14）**：装配阶段将部分 SG90 升级为 SG92R（金属齿轮舵机），后者堵转扭矩与寿命更优、更耐机械臂频繁受力；数量以实物为准，单价略高于 SG90，属同功能替代，不改变清单总额口径。
- **DC-DC 降压模块型号调整（10/16）**：舵机供电用 5V 降压模块在 10/16 更换为另一等价型号（输出 5V 满足舵机星形分电需求）；以实物贴标型号为准，性能等价。
- **幻尔成品底盘到货并装车（10/19 前）**：幻尔四驱差速双层底盘已到货，队伍已在其上完成器件装车，整车底盘以该成品底盘为最终形态；原激光切割铝板/碳纤维底盘方案并行保留作备用。
